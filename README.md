# Portofolio Digital Darius Wijaya

Website portofolio untuk tugas BK Kelas XII, dengan HTML, CSS, dan JavaScript.

## Membuka lokal
Buka `index.html` menggunakan browser. Semua aset proyek ada di `assets/`. Koneksi internet diperlukan untuk memuat font Google; jika offline, font cadangan akan digunakan.

## Cara publikasi GitHub Pages
1. Masuk ke https://github.com dan buat repository publik baru bernama `darius-portfolio` (atau nama lain).
2. Pilih **Add file → Upload files**. Upload **isi folder ini** (`index.html`, `style.css`, `script.js`, `.nojekyll`, dan direktori `assets`), bukan folder pembungkusnya. Jika antarmuka upload tidak mendukung folder, drag-and-drop semua file dari folder portofolio, termasuk folder `assets`, ke area upload.
3. Commit changes ke branch `main`.
4. Buka **Settings → Pages → Build and deployment**, pilih **Deploy from a branch**, branch `main` dan folder `/(root)`, lalu **Save**.
5. Buka alamat yang muncul di menu Pages, umumnya `https://USERNAME.github.io/darius-portfolio/`. Ganti USERNAME dengan nama akun GitHub sebenarnya.
